## Highlights

A polish release focused on the security- and setup-adjacent surfaces: the `/sandbox` and `/permissions` panels get clearer status text and live feedback, and the install instructions spell out exactly what to run for both the native binary and the npm package.

### Sandbox

- **`/sandbox` status line is clearer** — The picker now shows whether auto-allow and unsandboxed-fallback are on or off in the status text itself (e.g. `✓ sandbox enabled (auto-allow), fallback allowed`), so you can tell at a glance whether commands will prompt you. The leading icon flips to `⚠` whenever a required dependency is missing.
- **`/sandbox exclude` works on more command shapes** — Leading env-var assignments and safe wrappers (`timeout`, `env`, etc.) are stripped before matching, so a pattern like `"bazel:*"` now matches `FOO=bar timeout 30 bazel run //...` too. Compound commands (`docker ps && curl evil.com`) are checked per side.
- **Live settings refresh** — Toggling mode, override, or excluded commands applies to the sandbox runtime immediately — no restart needed.
- **Better Dependencies tab hints** — Each missing component on Linux (`bubblewrap`, `socat`, `ripgrep`) and macOS (`ripgrep`) shows the exact install command for your distro.
- **Managed-policy lockout surfaced in the picker** — When an organization / MDM settings file sets any `sandbox.*` key, the picker shows the `(managed)` tag and becomes read-only, matching the docs.

### Permissions

- **Immediate apply from `/permissions`** — Adding or deleting a rule from the interactive UI is applied to the live permission check on the next tool call — no restart required.
- **Shadowed-rule warnings** — `sharedRuleDetection` surfaces warnings when a later rule in the same list is unreachable because a broader earlier rule already matched, so you can clean up dead rules.
- **Legacy alias normalization** — `Task` → `Agent`, `KillShell` → `TaskStop`, `AgentOutputTool` / `BashOutputTool` → `TaskOutput`. Write either form and the canonical one is stored.
- **Clearer mode cycle list** — `disableBypassPermissionsMode` and `disableAutoMode` (each taking the literal `"disable"`) hide the corresponding mode from the cycle list, matching the Permissions Guide.

### Installation

- **Native binary (recommended)** — Single-line install with bundled sandbox helpers and self-update:
  ```bash
  curl -fsSL https://puku-cli.pkgs.puku.sh/install.sh | bash
  puku-cli doctor
  ```
  On Linux the installer prompts to add `bubblewrap`, `socat`, and `ripgrep`. Pin a version with `PUKU_VERSION=v1.8.66`; update later with `puku-cli update`.

- **npm package** — For macOS / Windows users (and anyone managing Node tools globally):
  ```bash
  npm install -g @puku/puku-cli
  puku-cli doctor
  ```
  Requires **Node.js 20+**. On Linux, also install `bubblewrap`, `socat`, and `ripgrep` from your distro's package manager — they have to match the kernel and glibc and can't be vendored. Update with `npm update -g @puku/puku-cli`.

- **bun** — `bun add -g @puku/puku-cli` works identically to the npm install.

Run `puku-cli doctor` after either install to verify the binary, `PATH`, sandbox readiness, and version currency.
