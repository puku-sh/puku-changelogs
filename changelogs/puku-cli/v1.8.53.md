## Highlights

Sub-agent transcripts (the long-running parallel tasks the CLI spins up) now stream over Remote Control — both as live message frames and as a complete transcript replayed when you reconnect. Tool-use summaries also stream to the paired device by default. Renaming a session from a paired device now actually renames it on the CLI side (it used to reply "success" without doing anything).

### New Features

- **Sub-agent transcripts in Remote Control** — The output from sub-agents and teammates (long-running parallel tasks) now reaches your paired device, not just the terminal. You'll see a live feed as the agent works, and a complete transcript when it finishes — including its reasoning, not just the tool calls. Reconnecting from a second device or reloading the browser replays the full transcript.

- **Tool-use summaries in Remote Control** — Each tool call now arrives at the paired device with a clean human-readable summary (which file was edited, which command was run, what was returned), instead of the paired device having to infer it from raw frames. This is on by default.

- **Cleaner tool-use summary labels** — The labels shown for tool-use summaries are now sanitized for remote rendering, so what you see on the paired device matches what you'd see in the terminal — without local-only jargon or formatting glitches.

### Bug Fixes

- **Renaming a session from a paired device actually renames it** — Renaming a session from your phone or browser used to reply "success" without changing anything locally. Three issues were fixed at once: the session identifier used for the rename was the wrong one, the prompt-bar badge never updated, and a session that already had a title kept replaying the old name to newly-paired clients. Renaming from a paired device now works end-to-end, and the rename is correctly attributed to the device that initiated it.
