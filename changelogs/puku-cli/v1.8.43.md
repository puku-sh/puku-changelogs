## Highlights

A cleaner, more semantically-named set of color theme tokens (so the dark, light, daltonized, and ANSI themes look more consistent and accessible), a new way to grant scoped access to specific paths via `@path` mentions in prompts, and a default model upgrade across all model-selection surfaces.

### New Features

- **Refreshed theme tokens** — The CLI's color system has been reorganized into a clearer set of named tokens (info, prompt, accent, surface, panel, border, secondary, muted, cursor), so the dark, light, daltonized, and ANSI themes look more consistent and accessible. Status lines, banners, and other CLI output pick up the active theme dynamically.

- **`@path` mentions authorize scoped access** — When you reference a path with `@` in a prompt (for example `@./notes.md` or `@~/projects/foo`), the CLI records that path as user-anchored for the rest of the session. Read and write inside those directories are then allowed without further prompts, while the rest of your filesystem stays protected. The diagnostic message when a path is blocked now lists the paths you've already anchored, so it's clear what's in scope.

- **New default model across the CLI** — The default model is now `puku-ai-2.8` everywhere a default appears: settings, the model picker, environment-driven resolution, and `/doctor` reports.

- **Stricter model pinning** — Built-in agents and teammates now only accept pinned models, so the routing surface is more predictable and unsupported models are caught at the boundary instead of failing later.
