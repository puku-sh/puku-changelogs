## Highlights

The big change this release is a much richer Remote Control experience. Paired phones and browsers can now see exactly what the CLI is doing in real time — when it's thinking, when it's idle, when it finishes a turn, what background agents are up to, and the same task list that the terminal renders. Email login is also added as an option alongside the existing providers.

### New Features

- **Live turn status in Remote Control** — When you're controlling the CLI from your phone or browser, you can now see when a turn starts, when it ends, and how long it took. The old "is it still working?" guess is gone — the paired client always knows.

- **Background agent and teammate progress** — Sub-agents and teammates (those long-running parallel tasks the CLI spins up) now report live progress to Remote Control, with a spinner row and elapsed time. When they finish, you get a checkpoint event so the row clears.

- **Session task list in Remote Control** — The same task checklist the local terminal renders is now visible on your paired device, updated in real time as items move from pending to in progress to complete. Reloading the browser or reconnecting from a second device shows the current state of the list immediately.

- **Permission and approval prompts survive reconnects** — If your phone disconnects (backgrounded the app, network blip) while a permission or approval prompt is on screen, the prompt now comes back the next time you reconnect, instead of leaving the CLI stuck waiting on a response that never arrived.

- **Interrupt handling is correctly reported** — When you interrupt a turn (Ctrl+C locally, or an interrupt button in Remote Control), the paired client now sees that the turn was stopped, not that it completed.

- **Mid-turn reconnection snapshots** — If you open a fresh Remote Control session while a turn is already running, the new session immediately sees that the CLI is busy, instead of looking identical to "nothing happening."

- **Live model and permission-mode sync** — When you change the model or permission mode in the CLI, your paired device now picks up the change immediately, instead of waiting for the next reconnect.

- **Email login** — The login picker now offers email alongside the existing options.

- **Stress-tested frame ordering** — The Remote Control wire protocol is backed by an end-to-end stress test that runs hundreds of tool calls across multiple turns and verifies that idle notifications always arrive after the last content frame, never out of order.

### Bug Fixes

- **Empty conversations no longer export to a blank file** — Exporting a conversation with no messages now shows a clear message instead of silently writing an empty file.

- **Stale state after a client handoff** — When a paired device swapped out (e.g. switching phones), the new client used to show the previous device's model and permission mode until something else changed locally. The new device now picks up the current state immediately on connect.
