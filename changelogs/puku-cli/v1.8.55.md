## Highlights

Three related Remote Control fixes in one release. The paired device now shows live compaction status (not just after-the-fact), the actual post-compaction content reaches the paired device for both auto-compaction and manual `/compact` (previously it was clamped out), and `/clear` now sends a clear marker so paired clients can tell where one conversation ends and the next begins.

### New Features

- **Live compaction status in Remote Control** — When the CLI is compacting your context (either automatically mid-turn, or because you ran `/compact`), your paired device now shows a live "compacting" indicator alongside the existing "thinking" and "idle" states. The status returns to the real session state when compaction finishes, regardless of whether compaction happened mid-turn or standalone.

### Bug Fixes

- **Auto-compaction no longer desyncs the remote transcript** — When the CLI compacted your context automatically, the paired device used to fall out of sync with the terminal — it never received any signal, and the post-compaction content (the boundary marker, the summary, the kept tail) was clamped out by the message-diffing resend. The paired device now receives a clear signal when auto-compaction finishes, and the actual post-compaction content reaches it correctly.

- **Manual `/compact` post-compaction content reaches Remote Control** — Running `/compact` from the CLI terminal used to leave the paired device with the pre-compaction transcript and no signal that anything had changed. The post-compaction content now reaches the paired device, and a clear signal marks the boundary, across all three compaction backends.

- **`/clear` looks like a clear in Remote Control** — Running `/clear` from the CLI terminal used to look identical to "this conversation just kept going" on a paired device — the pre-clear and post-clear conversation were glued seamlessly together, with no way to tell them apart. A clear marker now arrives at the paired device, so a freshly-paired client sees the boundary and only the post-clear conversation from then on.
