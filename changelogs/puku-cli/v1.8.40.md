## Highlights

This release replaces the browser-redirect login flow with a copy-paste device-code flow that works in every terminal, headless container, and SSH session — no local web server or browser handoff required. It also fixes the Shift+Tab keyboard shortcut on Windows terminals so the permission-mode cycle works again.

### New Features

- **Copy-paste device-code login** — The login flow now uses a one-time code displayed in the terminal. Paste that code at the verification URL in any browser, and the CLI picks up the session automatically. Works in remote shells, SSH sessions, headless containers, and other environments where a browser round-trip on the same machine isn't possible.

### Bug Fixes

- **Shift+Tab now cycles permission modes on Windows terminals** — The "cycle permission mode" keyboard shortcut was being dropped on Windows terminals (legacy Conhost, Windows Terminal, and Kitty-on-Windows), so users had no way to change permission mode from the keyboard. Shift+Tab now works consistently across all supported terminals.
