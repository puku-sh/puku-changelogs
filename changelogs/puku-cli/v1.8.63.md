## Highlights

Permission checks for user-level skills directories now follow your config (instead of getting silently refused), and the install script keeps going cleanly through non-interactive `sudo` environments.

### Bug Fixes

- **User-level skills directory permissions now follow your config** — If you've told Puku CLI that a particular user-level directory is fair game (via your `~/.puku/` config), permission checks for that directory now honor that setting instead of denying it. Previously, some user-level skills paths were silently blocked.
- **`sudo` install script handles non-interactive environments** — A `curl | bash` run on a CI runner or in any other environment where `sudo` is installed but not configured for passwordless use now completes without halting halfway. The script also leaves behind an install marker in the global config so the runtime knows it was installed natively, immediately, rather than on next launch.
