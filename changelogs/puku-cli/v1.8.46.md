## Highlights

Puku CLI now recognizes ambient API keys out of the box. If `PUKU_AI_API_KEY` is set in the environment, the OAuth login flow is skipped entirely and the CLI runs against the key directly — useful for CI, containers, and CI/CD agents that already have a managed credential.

### New Features

- **Ambient API-key auth bypass** — `authLogin` now skips the OAuth login flow if an API key is already configured via `PUKU_AI_API_KEY`. `useApiKeyVerification` was updated to handle ambient keys and stop emitting spurious loading states when the verification path doesn't actually need to run. `getAuthTokenSource` and the related auth helpers now recognize ambient keys so the right source is reported back to the user and to telemetry. A new markdown file documents the supported ambient environment variables for user guidance.
