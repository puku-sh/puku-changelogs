## Highlights

A small but useful installer pass: the `install.sh` flow now reports failures from the sandbox prerequisite step clearly instead of swallowing them, and a handful of internal inconsistencies between the install script and the in-app `/install` command were aligned.

### Bug Fixes

- **Sandbox prerequisite install surfaces real errors** — When the install script tries to install the Linux sandbox host packages (`bubblewrap`, `socat`, `ripgrep`) on a system that needs `sudo`, the previous release could silently no-op and leave the user in a half-installed state. The script now checks whether the prerequisite step actually ran and reports a clear error if it didn't.
- **Sandbox bridge socket paths are no longer ignored** — Some installs left sandbox bridge sockets lying around in the working directory because they weren't matched by `.gitignore`. They now are, so a clean checkout stays clean.
