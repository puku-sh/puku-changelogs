## Highlights

Built-in agents and teammates now go through a single model-pinning gate, so only supported models are accepted and the lightweight models are used where they make sense for performance. The fast-mode model resolver no longer leaks a stale marker into the resolved model id. A guide agent that was crashing the CLI on some machines is temporarily disabled until the underlying issue is fixed.

### New Features

- **Built-in agents only use pinned models** — Agents and teammates the CLI spawns internally now only accept pinned models. If something tries to dispatch them with an unsupported model, you get a clear error at the boundary instead of a confusing failure later. The lightweight pinned model is used where it makes sense for performance.

### Bug Fixes

- **Fast-mode model id no longer carries a stale marker** — The fast-mode model resolver used to leave a stale internal marker attached to the model id it returned. That marker could leak into downstream displays and model-name lookups. The marker is removed, and the constraints are now documented where the resolver lives.

- **CLI no longer crashes on machines hitting the failing guide-agent path** — A built-in "guide" agent was triggering runtime errors on some setups, taking the whole CLI down at startup. That agent is temporarily disabled while the underlying issue is fixed.
