## Highlights

A small focused release: the `/statusline` command is temporarily disabled while its UX is being reworked, and the description of the new default model has been updated to reflect its underlying fine-tuning.

### Changes

- **`/statusline` temporarily disabled** — The `/statusline` command and its related tips have been turned off while the experience is being reworked. The command will return in a later release.

- **Updated description for the default model** — The user-facing description of the `puku-ai-2.8` default model has been refreshed, so the model picker and `/doctor` reports describe what you actually get.
