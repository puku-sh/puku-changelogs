## What's New

**Faster Long Chats** — Long chat sessions now load much faster. Instead of loading everything at once, turns load as you scroll and unload when you're not looking at them — so even very long conversations stay smooth and responsive.

**Nicer Code Blocks** — Code in assistant responses now renders with proper syntax highlighting, a file header when relevant, and a clean copy button.

**macOS Auto Update** — Puku can now update itself on macOS. When an update is available, it installs in the background and relaunches automatically — no admin password needed.

**Go Language Support Restored** — Go workspaces now get proper language support again after a previous regression.

## Fixes

- Fixed file edit previews being slow or freezing when the agent made large changes
- General stability and reliability improvements
