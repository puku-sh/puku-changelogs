> **Platform:** This release is available on **Linux and macOS only**.

## Fixes

**Agent Loop Break** — Fixed an issue where the agent could exit its work loop before a task was actually finished. During longer or multi-step jobs — such as editing several files, running commands, or working through a plan — the agent would sometimes stop early, respond as if it were done, or fail to continue to the next step on its own.

This release improves how the agent stays in its execution loop until the task is complete, or until you explicitly stop it. You should see more reliable follow-through on multi-step requests, fewer cases where you have to nudge the agent to continue, and more consistent behavior when it chains tool calls together.

- Fixed the agent breaking out of its loop unexpectedly during multi-step tasks
- Fixed cases where the agent stopped mid-task and reported completion too early
- Improved reliability when the agent chains multiple tool calls in one request
- General stability improvements
