## What's New

**Fewer Crashes on Long Sessions** — Puku now manages memory much more aggressively during long coding sessions. It clears out old data as you work, so memory stays bounded instead of growing until the editor crashes.

**Smoother Large File Edits** — File edit previews in chat now load gradually as you scroll, instead of all at once. This stops the editor from freezing or becoming unresponsive when the agent makes large changes.

**Better Memory Monitoring** — Puku now tracks renderer memory usage in the background and can act earlier to prevent out-of-memory crashes before they happen.

## Fixes

- Fixed a critical bug where every agent tool call was failing with an error — this was causing complete tool outages for affected users
- Fixed the agent stalling or crashing mid-task on long agentic runs because memory compaction wasn't triggering at the right time
- Fixed a crash when the embeddings cache referenced an old model that no longer exists
- Fixed a background error that was preventing session context stats from being saved to disk
- Fixed the agent sometimes losing its stream mid-task and not recovering
- General stability and reliability improvements
