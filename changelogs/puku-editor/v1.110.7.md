## What's New

**Diff View for Edits** — File edit previews in chat now show changes as a proper diff, with added lines in green and removed lines in red.

**New Chat Toolbar** — A small ring now shows how much context your chat session has used, plus a new button to attach images and a clearer stop button to cancel a running agent.

**Faster Tab Switching** — Switching between chat tabs is now instant, even with long conversations. Chats no longer freeze or reload when you switch back to them.

**Smarter Codebase Search** — Search results now include nearby code, not just an isolated snippet — so the agent understands context better and needs fewer extra file reads.

## Fixes

- Fixed a crash that could happen during conversation summarization
- Fixed search results sometimes showing "undefined" instead of the file name and line numbers
- Fixed custom agents missing from the mode picker on Windows
- General stability improvements
