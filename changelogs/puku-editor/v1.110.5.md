## What's New

**Plan Mode** — The agent can now make a plan before making changes. It asks a few quick questions, shows you the plan, and waits for your approval before building.

![Plan Mode approval flow](https://raw.githubusercontent.com/puku-sh/puku-changelogs/main/changelogs/puku-editor/assets/v1.110.5/plan-mode-img.png)

**Auto Update (Linux & macOS)** — Puku can now update itself. No more manual downloads — it installs the update for you.

**Smarter Agent** — The agent now handles multiple tasks at once, sees your code errors automatically, and keeps better track of its to-do list during long tasks.

**New Agent Tools**

- Can ask you questions when it needs more info
- Can manage multiple terminals at once
- Long commands now run in the background instead of freezing things

**Image Support in Chat** — You can now attach images to chat messages and reference them with `#file`. Attached images persist correctly across conversation turns.

![Image attachments in chat](https://raw.githubusercontent.com/puku-sh/puku-changelogs/main/changelogs/puku-editor/assets/v1.110.5/Image-file.png)

**Better Code Understanding** — Now supports 28 programming languages for smarter code editing and search.

## Fixes

- Fixed crashes when opening certain file types
- Terminal commands run normally again (no more popups)
- Added a safety check before running commands with passwords or keys
- Agent no longer accidentally rewrites whole text/Markdown files
- Fixed errors with `.json` files, and Ruby/Rust code support
- Fixed several Plan Mode bugs (wrong tabs, lost chat history, stuck buttons)
- Fixed chat colors not matching in light/dark mode
- Fixed chat sometimes freezing or showing errors during long responses
- General stability improvements
