## What's New

**Max Plan** — Puku now supports a Max subscription plan, giving eligible users access to higher usage limits.

## Fixes

- Fixed quota errors not showing clearly in chat — when you hit a usage limit, you'll now see a specific message explaining what happened instead of a generic failure
- Fixed subscription plan checks not working correctly in some cases due to outdated API routing
- General stability improvements
